# Definition of Done — RentWise Pro

A feature is "Done" when:
- Code merged via PR
- CI is green
- Manual smoke test performed and described in PR
- Docs updated (STATUS + ROADMAP)

## MVP Release Criteria (Phase 1)
- Search + Save flow works end-to-end
- Purchase Sheet generates a complete cash-to-close estimate
- ROI Forecast shows correct metrics for at least 3 test properties
- User can adjust assumptions and see updated outputs
- App runs from a clean clone with documented setup steps
